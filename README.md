# A Letter for My Bossy Girl

An interactive letter built with HTML, CSS, and JavaScript, with no production
dependencies. It is ready to publish directly with GitHub Pages.

## Publishing

1. Create a new repository on GitHub.
2. Upload every file in this folder to the `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch, the `/ (root)` folder, and save.

GitHub will display the public address once deployment is complete.
